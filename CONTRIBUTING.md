# Como contribuir

1. Escolha uma issue e mova para "Em andamento" no quadro.
2. Crie uma branch: `feat/<area>-<descricao>`, por exemplo `feat/dados-silver`.
3. Abra um Pull Request com `Closes #<número da issue>`.

Padrão de commit: `tipo(area): descrição`
- Tipos: `feat`, `fix`, `docs`
- Áreas: `dados`, `agente`, `portal`, `bi`, `pm`

Não suba chaves de API, arquivos `.env` ou o CSV completo do Kaggle.
