# Conteúdo revisado

Este diretório ainda não contém FAQ ou políticas oficiais do grupo. Stephanie coordenará a revisão. Copie o modelo de `../templates/atendimento.json` para um novo arquivo JSON aqui, preencha as informações e registre revisão, fonte e versão. O indexador de conteúdo real só aceita `status: approved` com `approved_by` preenchido.

Não marque conteúdo como aprovado apenas para fazer o programa funcionar. Para aprender, use os exemplos separados de `../demo/` e a opção `--demo`.
